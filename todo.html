Task 3 // JavaScript Logic & State Management

A state-driven To-Do List.

Full CRUD, automatic persistence to window.localStorage, and status filtering — built with vanilla JS, dynamic DOM creation, and a single delegated event listener rather than one per task.

    Implementation notes

    CRUD
    Create, rename (double-click to edit), toggle complete, and delete — all handled through one delegated click/dblclick listener on the list container.
    Persistence
    State is a plain array of task objects, serialized to localStorage on every change and rehydrated on page load.
    Filtering
    All / Active / Completed views are derived from the same state array — no duplicate DOM, just a re-render with a filter predicate.
    Rendering
    Task elements are built with document.createElement rather than innerHTML string concatenation, to avoid injection risk from task text.
